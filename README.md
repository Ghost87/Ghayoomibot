# قیومی‌بات | GhayoomiBot 🤖

بازنویسی حرفه‌ای ربات رسمی **کالج آموزش زبان علی قیومی** بر اساس مستندات مهندسی معکوس —
کاملاً Asynchronous با **aiogram 3.x**.

---

## ✨ امکانات

- 🔒 **قفل جوین اجباری** روی ۴ کانال (@Ariamir_academy, @ARIAMIR_DEV, @ZARMEH_IR, @ARIAMIR_Studio) + دکمه «بررسی عضویت»
- 🏠 **منوی اصلی شیشه‌ای ۶ ردیفه** مطابق ربات اصلی
- 📱 **پشتیبانی از Telegram Mini Apps** (پنل دانش‌آموزی، جزوات، لایسنس، پیام ناشناس، پشتیبانی آنلاین)
- 🎁 صفحه دریافت جزوه فیزیک دوازدهم نهایی
- 📞 زیرمنوی «راه‌های ارتباطی» (تماس، سایت، ایتا/روبیکا/بله، آپارات، قیومیکست، اینستاگرام)
- 🤝 **فرم استخدام ۹ مرحله‌ای (FSM)** با ۷ موقعیت شغلی و ارسال رزومه به گروه ادمین
- 📝 تمام متون **عیناً کلمه‌به‌کلمه** از ربات اصلی (حتی با غلط‌های املایی نسخه اورجینال مثل «تحصلی» و «از قتی»)

## 📁 ساختار پروژه

```
ghayoomo_bot/
├── bot.py                      # نقطه ورود و راه‌اندازی Dispatcher
├── config.py                   # توکن، کانال‌ها، لینک‌ها و متون ثابت (Verbatim)
├── requirements.txt
├── .env.example
├── keyboards/
│   ├── main_menu.py            # منوی اصلی + زیرمنوهای جزوه/پنل/ناشناس
│   ├── join.py                 # کیبورد قفل جوین اجباری
│   ├── contact.py              # راه‌های ارتباطی (۷ ردیف)
│   └── cooperation.py          # ارسال رزومه + ۷ موقعیت شغلی (۲ستونه)
├── handlers/
│   ├── start.py                # /start و بررسی عضویت
│   ├── menu.py                 # منوی اصلی و زیرمنوها
│   ├── cooperation.py          # فرم استخدام ۹ مرحله‌ای (FSM)
│   └── fallback.py             # پیام‌های پراکنده → منوی اصلی
├── states/
│   └── cooperation.py          # CooperationFSM
└── services/
    ├── check_membership.py     # بررسی عضویت در کانال‌ها
    └── admin_notify.py         # ارسال رزومه به گروه ادمین
```

## 🚀 راه‌اندازی (۳ قدم)

```bash
# 1) نصب وابستگی‌ها
pip install -r requirements.txt

# 2) تنظیم متغیرهای محیطی
cp .env.example .env
#    سپس BOT_TOKEN و ADMIN_GROUP_ID را داخل .env پر کنید

# 3) اجرا
python bot.py
```

## ⚙️ نکات راه‌اندازی مهم

| مورد | توضیح |
|---|---|
| توکن | از [@BotFather](https://t.me/BotFather) بگیرید و در `.env` قرار دهید |
| جوین اجباری | برای کانال‌های **عمومی** (دارای @username) چیزی لازم نیست؛ تلگرام امکان بررسی عضویت را می‌دهد. فقط اگر کانالی **خصوصی** است، ربات باید عضو/ادمین آن باشد |
| گروه ادمین | ربات باید **عضو گروه ادمین** باشد تا رزومه‌ها به آن جا برسد؛ `ADMIN_GROUP_ID` آیدی عددی گروه است (با `-100` شروع می‌شود — پیش‌فرض: گروه Arsourcer) |
| مینی‌اپ‌ها | مسیرهای web_app در `config.py` قابل تنظیم‌اند |
| دیتابیس | SQLite در `data/bot.db` — ریست کامل با `python reset_db.py` |

## 🔐 پنل ادمین (`/admin`)

ورود: `/admin` ← نام‌کاربری ← رمز عبور (۳ تلاش اشتباه = مسدودی موقت)

| بخش | قابلیت |
|---|---|
| 📊 آمار ربات | کل کاربران / ۲۴ساعت / ۷روز / رزومه‌ها + تعداد اعضای کانال‌ها |
| 📢 پیام همگانی | هر نوع محتوا (متن/عکس/فایل) با پیش‌نمایش و تأیید + گزارش موفق/ناموفق |
| 👥 مدیریت کاربران | لیست صفحه‌بندی‌شده، جستجو (نام/یوزرنیم/آیدی)، کارت کاربر، رزومه‌هایش، ارسال پیام تکی |
| 📥 خروجی CSV | CSV کاربران و رزومه‌ها (سازگار با اکسل فارسی — BOM) |
| 📣 کانال‌های جوین | افزودن / حذف / ویرایش عنوان کانال‌های اجباری |
| 🎁 دکمه هدر منو | ویرایش متن دکمه، متن بدنه، افزودن/حذف دکمه لینک، ست/حذف فایل |
| 📞 راه‌های ارتباطی | افزودن/حذف/ویرایش دکمه‌ها (لینک، مینی‌اپ، آلرت) |
| 🤝 موقعیت‌های شغلی | افزودن/حذف/ویرایش مشاغل فرم همکاری |
| 📝 متن سؤال‌ها | ویرایش متن هر ۹ سؤال فرم استخدام |
| 🗄 ریست دیتابیس | برگشت به حالت کارخانه با تأیید |

تنظیمات در جدول `settings` ذخیره و بلافاصله برای کاربران اعمال می‌شود.
دسترسی مستقیم (بدون لاگین): متغیر `ADMIN_USER_IDS` در `.env`

## 🧩 جریان فرم استخدام (FSM)

```
همکاری با ما  →  ارسال رزومه  →  انتخاب ۱ از ۷ موقعیت شغلی (کیبورد ۲ستونه)
  → ۱) نام و نام خانوادگی
  → ۲) استان
  → ۳) شهر
  → ۴) تاریخ تولد (با مثال 1380/01/01)
  → ۵) مدرک تحصیلی و دانشگاه (با مثال)
  → ۶) رشته تحصیلی
  → ۷) سابقه همکاری (پاسخ متنی)
  → ۸) مهارت‌ها
  → ۹) رزومه/توضیحات تکمیلی
  → 📥 ارسال به گروه ادمین + پیام موفقیت + کیبورد ریپلای «بازگشت به منوی اصلی»
```

متن سؤال‌ها عیناً از اسکرین‌شات‌های ربات اصلی برداشته شده است.
`/start` یا `/cancel` در هر مرحله فرم را ریست می‌کند.

## 👑 پنل مدیریت مخفی (بازنویسی حرفه‌ای — ۲۰۲۶/۰۷/۳۱)

پنل هیچ دکمه‌ای در کیبورد کاربر ندارد! فقط با کامند `/admin` ← نام‌کاربری ← رمز عبور باز می‌شود
(۳ تلاش اشتباه = بلاک موقت ۱۰ دقیقه‌ای؛ آیدی‌های `ADMIN_USER_IDS` بدون لاگین مستقیم وارد می‌شوند).

| بخش | قابلیت |
|---|---|
| 📊 آمار زنده | کل/۲۴ساعت/۷روز کاربران + رزومه‌ها + تعداد اعضای کانال‌ها + 🔄 بروزرسانی |
| 📢 پیام همگانی | هر نوع محتوا (متن/عکس/فایل) با پیش‌نمایش و تأیید + گزارش موفق/ناموفق |
| 👥 مدیریت کاربران | لیست صفحه‌بندی (۸ در هر صفحه) با دکمه‌های نام+یوزرنیم، 🔍 جستجو (نام/یوزرنیم/آیدی)، کارت کاربر، مشاهده رزومه‌ها، ✉️ پیام تکی، 🗑 حذف کاربر |
| 📥 خروجی و بکاپ | CSV کاربران و رزومه‌ها (سازگار با اکسل فارسی — BOM) + 📦 دانلود فایل دیتابیس |
| 📣 کانال‌های جوین | افزودن (۳ مرحله) / ویرایش عنوان / حذف با تأیید |
| 🎁 دکمه هدر منو | ویرایش متن دکمه و متن بدنه، افزودن/حذف دکمه لینک (🔗/📱)، ست/حذف فایل، 👁 پیش‌نمایش زنده |
| 📞 راه‌های ارتباطی | افزودن (متن/نوع/مقدار/ردیف)، ویرایش متن و مقدار، حذف |
| 💼 موقعیت‌های شغلی | افزودن / ویرایش / حذف با تأیید |
| 📝 متن سؤال‌ها | ویرایش متن هر ۹ سؤال فرم استخدام |
| 🗄 ریست دیتابیس | 📦 بکاپ CSV خودکار + 🧹 پاک‌سازی تاریخچه + ☠️ ریست کارخانه (هر دو با تأیید) |

همه بخش‌ها در همان «یک پیام» ویرایش می‌شوند و بازگشت‌ها یک‌مرحله‌ای‌اند.
